# BubbleBattler
Jogo de batalha entre personagens com habilidades únicas, desenvolvido em JavaScript com Vite.

## 🎮 Sobre o projeto

No BubbleBattler, o jogador seleciona um personagem para entrar em combate contra um oponente controlado por IA. Cada personagem possui habilidades e comportamentos próprios (ataque, cura, defesa), e a batalha continua até que um dos lados perca todos os pontos de vida.

**Status do projeto:** em desenvolvimento — novos personagens e ajustes de balanceamento das IAs sendo adicionados continuamente.

## 🚀 Tecnologias utilizadas

- JavaScript
- Vite
- HTML5 / CSS3

## 🧙 Personagens

O jogo conta com um sistema de personagens jogáveis, cada um com lógica própria de combate e habilidades especiais (ataque, cura, defesa). Novos personagens são adicionados periodicamente.

## ▶️ Como rodar o projeto

1. Clone o repositório:
```bash
   git clone https://github.com/Matheussaares/BubbleBattler.git
```
2. Instale as dependências:
```bash
   npm install
```
3. Rode o projeto em modo desenvolvimento:
```bash
   npm run dev
```

## 📌 Funcionalidades

- Seleção de personagem antes da batalha
- Sistema de pontos de vida e dano
- Lógica de combate individual por personagem (IA)
